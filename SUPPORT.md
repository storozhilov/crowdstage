# Support

CrowdStage is an early-stage open-source project.

- **Bug reports:** use GitHub Issues and include reproduction steps, expected behaviour, actual behaviour, and relevant logs with secrets removed.
- **Feature proposals:** open an issue describing the use case and why it matters.
- **Architecture discussions:** use GitHub Discussions if enabled, or open an issue labelled `proposal`.
- **Security reports:** follow [SECURITY.md](SECURITY.md); do not disclose vulnerabilities publicly.

Please note that maintainers may not be able to provide immediate support or guaranteed response times.
